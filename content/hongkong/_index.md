# GroupDocs.Search 教學 – 解鎖文件搜尋功能

GroupDocs.Search 是一個跨平台的函式庫，提供快速且可擴展的全文搜尋，支援超過 100 種文件格式。  

歡迎來到 **GroupDocs.Search 教學** 中心，這裡是一站式學習 .NET 與 Java 平台文件搜尋與索引的最佳去處。無論您是要構建快速的內部工具或大型企業解決方案，這些一步步的指南都能協助您實作快速、精確且可擴展的搜尋功能。透過探索 GroupDocs.Search 教學系列，您將迅速獲得在任何應用程式中加入強大搜尋功能的信心。

## 什麼是 GroupDocs.Search？

GroupDocs.Search 是一個函式庫，讓開發人員能在各種文件類型上建立索引、查詢與擷取文字，無需外部搜尋引擎。它支援超過 100 種檔案格式，包括 PDF、DOCX、XLSX、PPTX 以及影像檔，且能處理多 GB 規模的集合，同時提供次秒級的查詢回應，適用於小型工具與企業級搜尋平台。
