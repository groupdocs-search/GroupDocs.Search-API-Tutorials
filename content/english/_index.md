# GroupDocs.Search tutorial – unlock document search power

GroupDocs.Search is a cross‑platform library that provides fast, scalable full‑text search across more than 100 document formats.

## What is GroupDocs.Search?

GroupDocs.Search is a library that enables developers to index, query, and retrieve text from a wide variety of document types without needing external search engines. It supports over 100 file formats—including PDF, DOCX, XLSX, PPTX, and image files—and can process multi‑gigabyte collections while delivering sub‑second query responses, making it ideal for both small utilities and enterprise‑grade search platforms.
