# Πώς να Διαγράψετε το Ευρετήριο και να Εκτελέσετε Αναζήτηση Κειμένου με το GroupDocs.Search για Java

Στον σημερινό κόσμο που βασίζεται στα δεδομένα, η **πώς να διαγράψετε το ευρετήριο** γρήγορα ενώ παραδίδεται ταχύτατη αναζήτηση πλήρους κειμένου σε Java αποτελεί ανταγωνιστικό πλεονέκτημα. Είτε δημιουργείτε μια εσωτερική βάση γνώσης, μια αποθήκη νομικών υποθέσεων ή έναν κατάλογο προϊόντων ηλεκτρονικού εμπορίου, ένα καλά ρυθμισμένο δίκτυο αναζήτησης μπορεί να βελτιώσει δραματικά την ικανοποίηση των χρηστών. Σε αυτόν τον οδηγό θα μάθετε πώς να **ρυθμίσετε ένα δίκτυο αναζήτησης**, **δημιουργήσετε ένα αναζητήσιμο ευρετήριο**, **βελτιστοποιήσετε την απόδοση της αναζήτησης** και **διαγράψετε έγγραφα από το ευρετήριο** όταν χρειάζεται — όλα χρησιμοποιώντας το GroupDocs.Search για Java.

## Γρήγορες Απαντήσεις
- **Ποιος είναι ο κύριος σκοπός του GroupDocs.Search για Java;** Παρέχει αναζήτηση πλήρους κειμένου σε πάνω από 50 μορφές εγγράφων, επιτρέποντας γρήγορη ανάκτηση λέξεων-κλειδιών.  
- **Πώς εκτελώ αναζήτηση κειμένου σε κατανεμημένο περιβάλλον;** Αναπτύξτε ένα δίκτυο αναζήτησης, ευρετηριάστε έγγραφα σε έναν κύριο κόμβο και, στη συνέχεια, ερωτήστε οποιονδήποτε κόμβο.  
- **Μπορώ να διαγράψω έγγραφα από το ευρετήριο χωρίς να το ξαναχτίσω;** Ναι, χρησιμοποιήστε το Delete API για να αφαιρέσετε επιλεγμένα αρχεία, επιτυγχάνοντας ουσιαστικά *πώς να διαγράψετε το ευρετήριο* χωρίς πλήρη επανευρετηρίαση.  
- **Ποια έκδοση της Java απαιτείται;** JDK 8 ή νεότερη.  
- **Απαιτείται άδεια για παραγωγή;** Απαιτείται έγκυρη άδεια GroupDocs.Search· διατίθεται δωρεάν δοκιμή.

## Τι είναι η «εκτέλεση αναζήτησης κειμένου»;
Η εκτέλεση αναζήτησης κειμένου σημαίνει την ερώτηση ενός ευρετηρίου πλήρους κειμένου για την ανάκτηση εγγράφων που περιέχουν τις καθορισμένες λέξεις-κλειδιά ή φράσεις. Το GroupDocs.Search δημιουργεί ένα ανεστραμμένο ευρετήριο που κάνει αυτές τις αναζητήσεις εξαιρετικά γρήγορες, ακόμη και σε χιλιάδες αρχεία.

## Γιατί να ρυθμίσετε ένα δίκτυο αναζήτησης;
Ένα δίκτυο αναζήτησης διανέμει τις εργασίες ευρετηρίασης και ερωτήματος σε πολλούς κόμβους, επιτρέποντάς σας να **βελτιστοποιήσετε την απόδοση της αναζήτησης**, να κλιμακώσετε οριζόντια και να διατηρήσετε υψηλή διαθεσιμότητα. Αυτή η αρχιτεκτονική είναι ιδανική για αποθήκες εγγράφων επιχειρησιακού επιπέδου, όπου η καθυστέρηση και η διαπερατότητα έχουν σημασία.

## Πώς να Υλοποιήσετε και να Βελτιστοποιήσετε ένα Δίκτυο Αναζήτησης με το GroupDocs.Search για Java
Φορτώστε τη διαμόρφωσή σας, ξεκινήστε έναν κύριο κόμβο και, στη συνέχεια, προσθέστε κόμβους εργασίας που μοιράζονται την ίδια βασική διαδρομή και θύρα. Η ανάπτυξη του δικτύου με αυτόν τον τρόπο επιτρέπει σε οποιονδήποτε κόμβο να διαχειρίζεται αιτήματα ευρετηρίασης ή ερωτήματος, παρέχοντας σταθερούς χρόνους απόκρισης ακόμη και όταν ο αριθμός των εγγράφων αυξάνεται σε εκατοντάδες χιλιάδες.

### Επισκόπηση βήμα‑βήμα
1. **Ορίστε μια βασική διαμόρφωση** που περιλαμβάνει έναν κοινόχρηστο φάκελο και μια θύρα TCP.  
2. **Ξεκινήστε τον κύριο κόμβο** για να διαχειρίζεται το ευρετήριο και να συντονίζει τους κόμβους εργασίας.  
3. **Προσθέστε κόμβους εργασίας** που συνδέονται με τον κύριο, επιτρέποντας παράλληλη ευρετηρίαση και αναζήτηση.  
4. **Παρακολουθήστε τη χρήση πόρων** και ρυθμίστε τις ρυθμίσεις του σωρού JVM για να διατηρήσετε τη καθυστέρηση χαμηλή.

## Πώς να Διαγράψετε το Ευρετήριο στο GroupDocs.Search για Java
`SearchNode` αντιπροσωπεύει έναν κόμβο στο δίκτυο GroupDocs.Search που διαχειρίζεται λειτουργίες ευρετηρίασης και ερωτήματος. Η μέθοδος `delete` αφαιρεί τα καθορισμένα έγγραφα από το ευρετήριο.

### Βήματα άμεσης διαγραφής
- Καλέστε τη μέθοδο `delete` στο αντικείμενο `SearchNode`.  
- Παρέχετε έναν πίνακα σχετικών διαδρομών αρχείων.  
- Επιβεβαιώστε τις αλλαγές· το ευρετήριο ανανεώνεται άμεσα και οι επόμενες αναζητήσεις δεν επιστρέφουν πλέον τα αφαιρεθέντα αρχεία.

## Τι είναι ένα Δίκτυο Αναζήτησης;
Ένα **δίκτυο αναζήτησης** είναι ένα σύνολο διασυνδεδεμένων κόμβων που μοιράζονται ένα κοινό αποθετήριο ευρετηρίου, επιτρέποντας κατανεμημένη ευρετηρίαση και εκτέλεση ερωτημάτων. Παρέχει οριζόντια κλιμάκωση και ανθεκτικότητα σε σφάλματα για μεγάλες συλλογές εγγράφων.

## Πώς να Δημιουργήσετε Αναζητήσιμο Ευρετήριο (index documents java)
Η μέθοδος `add` ευρετηριάζει ένα έγγραφο στο ευρετήριο αναζήτησης. Προσθέστε έγγραφα στον κύριο κόμβο χρησιμοποιώντας τη μέθοδο `add`; το δίκτυο διαδίδει τις αλλαγές σε όλους τους κόμβους εργασίας. Αυτή η προσέγγιση εξασφαλίζει ότι κάθε κόμβος μπορεί να εξυπηρετήσει ερωτήματα ενάντια στο πιο πρόσφατο ευρετήριο χωρίς πρόσθετα βήματα συγχρονισμού.

### Κύριες ενέργειες
- Κατευθύνετε τον κύριο κόμβο προς το φάκελο που περιέχει τα αρχεία προέλευσης.  
- Κληθείτε τη διαδικασία ευρετηρίασης· το δίκτυο επεξεργάζεται κάθε αρχείο και ενημερώνει το ανεστραμμένο ευρετήριο.  
- Επαληθεύστε ότι τα αρχεία ευρετηρίου εμφανίζονται στον καθορισμένο φάκελο αποθήκευσης.

## Πώς να Αφαιρέσετε Ευρετηριασμένα Αρχεία (remove indexed files)
Όταν ένα έγγραφο καταστεί παρωχημένο, καλέστε το API `delete` με τη διαδρομή του. Το σύστημα αφαιρεί τις καταχωρίσεις του αρχείου από το ανεστραμμένο ευρετήριο, ελευθερώνοντας χώρο αποθήκευσης και αποτρέποντας παλαιά αποτελέσματα.

## Οδηγός Υλοποίησης

### Διαμόρφωση του Δικτύου Αναζήτησης
**Επισκόπηση:** Καθορίστε μια βασική διαδρομή και θύρα για το δίκτυο αναζήτησης, επιτρέποντας στους κόμβους να επικοινωνούν αποτελεσματικά.

#### Βήμα 1: Ορισμός Βασικής Διαμόρφωσης
```java
import com.groupdocs.search.options.*;
import com.groupdocs.search.scaling.configuring.*;

String basePath = "YOUR_DOCUMENT_DIRECTORY/output/AdvancedUsage/Scaling/DeletingDocuments/";
int basePort = 49104; // Change if necessary.
Configuration configuration = ConfiguringSearchNetwork.configure(basePath, basePort);
```

- **Παράμετροι:**  
  - `basePath`: Διαδρομή καταλόγου για λειτουργίες δικτύου.  
  - `basePort`: Αριθμός θύρας που χρησιμοποιείται από το δίκτυο αναζήτησης.

#### Βήμα 2: Επίλυση Προβλημάτων
Βεβαιωθείτε ότι η καθορισμένη θύρα δεν είναι αποκλεισμένη από ρυθμίσεις τείχους προστασίας ή χρησιμοποιείται από άλλη εφαρμογή. Προσαρμόστε την ανάλογα ώστε να αποφύγετε συγκρούσεις.

### Ανάπτυξη Κόμβων Δικτύου Αναζήτησης
**Επισκόπηση:** Χρησιμοποιώντας τη διαμόρφωσή σας, αναπτύξτε κόμβους στο δίκτυό σας για κατανεμημένη ευρετηρίαση και αναζήτηση.

```java
import com.groupdocs.search.scaling.*;

String basePath = "YOUR_DOCUMENT_DIRECTORY/output/AdvancedUsage/Scaling/DeletingDocuments/";
int basePort = 49104;
Configuration configuration = ConfiguringSearchNetwork.configure(basePath, basePort);
SearchNetworkNode[] nodes = SearchNetworkDeployment.deploy(basePath, basePort, configuration);

// Nodes are now deployed and ready for further operations.
```

- **Κύριες Επιλογές Διαμόρφωσης:**  
  - **Base Path & Port:** Αυτές οι τιμές πρέπει να ταιριάζουν με αυτές που χρησιμοποιήθηκαν στην αρχική σας διαμόρφωση για να εξασφαλιστεί η συνέπεια.

### Ευρετηρίαση Εγγράφων (`create searchable index`)
**Επισκόπηση:** Προσθέστε έγγραφα στο ευρετήριο αναζήτησης αποδοτικά χρησιμοποιώντας έναν κύριο κόμβο.

```java
import com.groupdocs.search.scaling.*;

String documentsPath = "YOUR_DOCUMENT_DIRECTORY/path/to/documents";
SearchNetworkNode masterNode = nodes[0];
IndexingDocuments.addDirectories(masterNode, documentsPath);
```

- **Σκοπός:**  
  - `masterNode`: Ο κύριος κόμβος που διαχειρίζεται την ευρετηρίαση εγγράφων.  
  - `documentsPath`: Διαδρομή προς τον φάκελο που περιέχει τα έγγραφα.

#### Συμβουλές Επίλυσης Προβλημάτων
Επαληθεύστε ότι οι διαδρομές των εγγράφων είναι σωστές και προσβάσιμες. Βεβαιωθείτε ότι τα δικαιώματα επιτρέπουν ανάγνωση από αυτούς τους φακέλους.

### Αναζήτηση Κειμένου στο Δίκτυο (`perform text search`)
**Επισκόπηση:** Εκτελέστε ολοκληρωμένες αναζητήσεις κειμένου σε όλο το ευρετηριασμένο δίκτυο.

```java
import com.groupdocs.search.scaling.*;

String query = "nulla";
SearchNetworkNode masterNode = nodes[0];
TextSearchInNetwork.searchAll(masterNode, query, false);
```

- **Παράμετροι:**  
  - `query`: Το κείμενο που αναζητάτε.  
  - `masterNode`: Κόμβος που εκτελεί την αναζήτηση.

### Διαγραφή Εγγράφων από το Ευρετήριο (`delete documents index`)
**Επισκόπηση:** Αφαιρέστε συγκεκριμένα έγγραφα από το ευρετήριο χρησιμοποιώντας τις διαδρομές αρχείων τους.

```java
import com.groupdocs.search.scaling.*;

SearchNetworkNode node = nodes[0];
String[] filePaths = {
    "YOUR_DOCUMENT_DIRECTORY/Lorem ipsum.pdf",
    "YOUR_DOCUMENT_DIRECTORY/Lorem ipsum.docx"
};
deleteDocuments(node, filePaths);

void deleteDocuments(SearchNetworkNode node, String... filePaths) {
    Indexer indexer = node.getIndexer();
    DeleteOptions options = new DeleteOptions();
    indexer.delete(filePaths, options);
}
```

- **Σκοπός Μεθόδου:**  
  - `node`: Ο στόχος κόμβος για τις λειτουργίες διαγραφής.  
  - `filePaths`: Διαδρομές εγγράφων που θα αφαιρεθούν από το ευρετήριο.

#### Επίλυση Προβλημάτων
Βεβαιωθείτε ότι οι διαδρομές αρχείων είναι ακριβείς και ότι τα αρχεία υπάρχουν στον κατάλογό σας. Εάν τα προβλήματα παραμένουν, ελέγξτε τα δικαιώματα δικτύου και τη συνδεσιμότητα.
